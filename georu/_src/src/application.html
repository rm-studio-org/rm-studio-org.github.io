5[[백엔드 구성||Backend]]

[[5.1 요청 처리 레이어||5.1 Request processing layers]]

[[설계 포인트||Design point]]

[[서비스 레이어의 비동기 실행기는 스레드가 정확히 1개여야 합니다. 1이 아니면 앱이 기동하지 않습니다. 이것이 "시스템 전체에서 실행은 하나"를 코드 수준에서 보장하는 두 번째 장치입니다(첫 번째는 실행 게이트).||The service layer's async executor must have exactly one thread; otherwise the app refuses to start. This is the second mechanism that enforces "one run system-wide" at code level (the first is the execution gate).]]

5.2[[보안 필터 체인||Security filter chain]]

[[모든 요청은 아래 7단계를 순서대로 지납니다. 앞 단계에서 막히면 뒤 단계는 돌지 않습니다.||Every request passes the seven stages below in order; a failure stops the chain.]]

  1. [[초기 설정 확인||Initial setup check]][[총관리자가 없으면 화면은 `/setup`, API 는 503 (30초 기억)||Without a super administrator, screens go to `/setup` and the API returns 503 (cached 30 s)]] → 503 SETUP_REQUIRED
  2. CSRF[[화면 요청은 쿠키 토큰 · 헤더 확인, HTTP Basic 호출은 제외||Screen requests check cookie token · header; HTTP Basic calls are exempt]] → 403
  3. [[인증||Authentication]][[폼 로그인 세션 또는 HTTP Basic. 5회 실패 시 15분 잠금||Form sign-in session or HTTP Basic. 5 failures lock the account for 15 minutes]] → 401
  4. [[계정 상태||Account status]][[지워지거나 중지된 계정은 바로 로그아웃||Removed or suspended accounts are signed out immediately]] → 401
  5. [[메뉴 권한||Menu permission]][[경로 → 메뉴 → 없음 · 조회 · 실행 판단. 표에 없는 경로는 관리자만||Path → menu → None · View · Execute. Paths not in the table are admin-only]] → 403 FORBIDDEN
  6. [[비밀번호 변경||Password change]][[관리자가 만든 계정은 먼저 비밀번호를 바꿔야 함||Accounts created by an admin must change the password first]] → 403 PASSWORD_CHANGE_REQUIRED
  7. [[실행자 기록||Executor record]][[로그인 이름을 실행자로 기록 — 헤더로 바꿀 수 없음||The signed-in name is recorded as executor — cannot be overridden by a header]]

[[공개 경로: `/login` · `/logout` · `/setup` · `/ui-assets/**` · `/actuator/health/**` 와 로그인 안내서.||Public paths: `/login` · `/logout` · `/setup` · `/ui-assets/**` · `/actuator/health/**` and the sign-in guide.]]
