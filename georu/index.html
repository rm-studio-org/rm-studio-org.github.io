Georu(거루)는 실제 이관 프로젝트에서 쓰던 엔진을 공개한 DB 이관 프레임워크입니다. 사람은 변환 규칙(SQL · Java)만 쓰고, 실행 통제 · 이관 엔진 · 검증 · 재실행 · 기록 · 운영 화면은 Georu 가 맡습니다.Georu is a database migration framework extracted from the engine we ran on real migration projects. People write only the transformation rules (SQL · Java); Georu handles execution control, the migration engine, verification, re-runs, records and the operation screens.

왜 Georu 인가Why Georu

이관 사고는 매번 같은 곳에서 납니다Migration accidents happen in the same places, every time

두 사람이 동시에 돌리고, 테스트하다 운영 데이터를 덮고, 몇 건이 빠졌는지는 끝나고 나서야 압니다. Georu 는 이 사고들을 사람의 주의력이 아니라 프레임워크의 구조로 막습니다.Two people run it at once, a test overwrites production data, and missing rows surface only at the end. Georu prevents these accidents by framework structure rather than by human attention.

역할 분담Division of work

업체는 규칙만, 흐름은 Georu 가You write the rules. Georu owns the flow.

Georu 는 라이브러리 묶음(jar 7개)으로 배포되고, 업체는 이를 의존성으로 넣어 이관 앱을 만듭니다. 실행 흐름은 Georu 가 쥐고, 업체 코드를 정해진 자리에서 부릅니다.Georu ships as a library bundle of seven jars. Vendors add it as a dependency to build a migration app; Georu owns the execution flow and calls vendor code at defined points.

동작 방식How it works

테이블 하나가 옮겨지는 길The path of one table

요청부터 건수 판정까지 모든 단계가 운영 저장소에 남습니다. 읽기와 쓰기는 메모리 큐로 분리되어, 느린 타겟이 소스 읽기를 붙잡지 않습니다.Every step from request to count verdict is recorded in the operations store. Reads and writes are separated by an in-memory queue, so a slow target never holds the source read.

빠른 시작Quick start

데모를 바로 실행Run the demo locally

Docker(Compose v2)와 메모리 8GB 이상이면 됩니다. 접속 후 관리자 계정을 만들고 안내서 → 데모 시작 가이드를 따라가세요.All you need is Docker (Compose v2) and 8 GB+ of memory. Create an admin account on first visit, then follow Guide → Demo getting started.

0.x 베타 — 1.0 전까지 공개 API 와 설정 키가 바뀔 수 있습니다.0.x beta — public APIs and config keys may change before 1.0.

$ git clone https://github.com/dvmoomoodv/georu-data-migration.git
$ cd georu-data-migration/examples/demo
$ cp docker/.env.example docker/.env
$ ./run-scripts/run-docker.sh db     # Oracle + MySQL
$ ./run-scripts/run-docker.sh build  # app image
$ ./run-scripts/run-docker.sh up     # → http://localhost:8083/ui
