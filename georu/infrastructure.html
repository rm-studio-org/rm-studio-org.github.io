15실행 방식 — 어디서든 돌린다Ways to run — anywhere

같은 이관 앱 하나를 세 방식으로 돌리며, 바뀌는 것은 프로파일과 접속 정보(환경 변수)뿐입니다. 개발 PC 에서 검증한 앱이 그대로 리허설 · 본 이관 서버로 갑니다.The same migration app runs three ways; only the profile and connection details (environment variables) change. The app verified on a developer PC goes unchanged to the rehearsal and production servers.

dev

로컬Local

개발 · 단위 테스트. ./gradlew bootRun 또는 실행 스크립트. 운영 저장소는 H2 파일 data/.Development · unit tests. ./gradlew bootRun or the run script. Operations store: H2 file data/.

dkr

도커Docker

예제 · 통합 시험 · 리허설. docker compose up (run-docker.sh). 운영 저장소는 H2 파일(볼륨).Example · integration testing · rehearsal. docker compose up (run-docker.sh). Operations store: H2 file (volume).

prd

서버Server

리허설 · 본 이관. java -jar 또는 컨테이너. 운영 저장소는 H2 파일 또는 MySQL(DBA 관리).Rehearsal · production. java -jar or container. Operations store: H2 file or MySQL (DBA-managed).
