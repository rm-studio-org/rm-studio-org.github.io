DB 이관 프레임워크DB migration framework · Apache 2.0 · 0.x beta

거룻배처럼, 데이터를 청크로 나눠
안전하게 나르는 이관 프레임워크Like a lighter boat — moving data
safely, one chunk at a time.

  • 코드로 — 사람은 테이블별 SQL · 변환 규칙만 작성
  • 안전하게 — 실행 게이트 · 실행 전 점검 · 4단계 테스트 모드
  • 보이게 — 청크별 진행률 · 보고서 · 운영 UI
  • As code — people write only per-table SQL and rules
  • Safe — run gate, pre-flight checks, four test modes
  • Visible — per-chunk progress, reports, operations UI
