02[[증적 보내기 — 예||Sending evidence — examples]]

[[Trivy 리포트 push||Push a Trivy report]]

$ trivy image --format json -o report.json nginx:1.25
$ curl -X POST "https://mori.example.com/ingest/trivy?hostname=web-01" \
    -H "Authorization: Bearer $MORI_INGEST_TOKEN" \
    -H "Content-Type: application/json" \
    --data-binary @report.json

[[상태 확인||Health check]]

$ curl -s http://localhost:18000/health/ready
$ curl -s http://localhost:18000/metrics | head

[[코드 리뷰 · 개인정보 흐름 인제스트는 MORI 가 제공하는 워크플로 템플릿(`/controls/code-review/workflow-template`)을 쓰는 것을 권장합니다 — OIDC 토큰 발급과 페이로드 형식이 이미 맞춰져 있습니다.||For code-review and privacy-flow ingest, use the workflow template MORI serves (`/controls/code-review/workflow-template`) — OIDC token issuance and payload format are already set up.]]
